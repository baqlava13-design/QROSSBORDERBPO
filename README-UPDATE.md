# Qrossborder update — 10 november 2026

Complete originele Vite/React projectstructuur behouden. Nieuwe copy, drie tarieven en nieuwe externe fotografie-referenties verwerkt in src/main.jsx.

## Foto’s
De nieuwe beelden worden opgehaald vanaf images.unsplash.com. Internetverbinding vereist. Als een foto niet laadt, wordt automatisch de originele lokale afbeelding uit public/images getoond. Dit is een tijdelijke oplossing; download en licentiecontrole van de externe afbeeldingen zijn aanbevolen vóór productie. De afgebeelde personen zijn illustratief en niet noodzakelijk Qrossborder-medewerkers.

`npm run build`
